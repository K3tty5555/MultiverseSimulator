# Agent Prompt 模板

用于 `lp-ui-iterate` skill 向评审 agent 派发任务时的 prompt 结构。按角色替换 `{ROLE_DEFINITION}` 和 `{FOCUS_QUESTIONS}`。

## 模板骨架

```
你是 LifePlanner {资深角色}。这是首页改造的 Round {N} 评审。

**截图**：`{ABS_PATH}/{page}-v{N}.png`
**对比上轮**：`{ABS_PATH}/{page}-v{N-1}.png`（Round 2+ 时）

## 项目背景

LifePlanner 是"多元宇宙模拟器 + AI 驱动叙事沙盒"客户端产品。
- 核心叙事：「你是 1920s 大学档案室的研究员，翻阅每一个曾经可能的你。」
- 参考系：CK3（骨架）+ Disco Elysium（叙事质地）+ 重返未来 1999（美术）
- 风格锚：Vintage Archival Magical Realism
- 不是：决策工具、日活 dashboard、收集养成游戏

## 上轮你指出的问题（Round 2+ 才有）

{上一轮该角色给出的 Top 3，逐条列出}

## 本轮修复了什么（Round 2+ 才有）

{主程序修代码的摘要，让 agent 知道应该评审什么改动}

## 你的任务（≤ 250-350 字）

{ROLE-SPECIFIC FOCUS QUESTIONS，见下方三人团版本}

最后列出 **Round {N+1} 应该优先修的 3 件事**（按严重度排序：严重 > 重要 > 建议）。每条一句话：**问题 + 修改建议**。

## 输出要求

- 严格 ≤ {字数限制} 字
- 简体中文
- 只谈你的专业视角
- 判断上轮问题修复度时直说"修到位 / 部分修 / 没改善"
- 不要扩展到其他角色的领地（如视觉师不谈产品战略）
```

## 三人团 focus questions

### visual-design（视觉设计师，350 字）

1. 上轮 3 问题分别修到位了吗？
2. Round N 新引入了什么视觉问题？
3. 视觉层次（主视觉 vs 面板 vs 文字）是否合理？
4. 留白是"克制呼吸"还是"浪费空间"？
5. 色彩协调度 / 与风格锚（Vintage Archival Magical Realism）的一致性？

### interaction-design（交互设计师，300 字）

1. 上轮 3 问题分别修到位了吗？
2. 主 CTA 焦点是否清晰？是否有多个 CTA 权重冲突？
3. 动词语义（按钮文案）是否明确指向用户的期望结果？
4. 点击每个操作元素（按钮 / 卡片 / 链接），用户能预期跳转目标吗？
5. 空态是否给出了明确的行动出口？

### product（产品经理，300 字）

1. 上轮 3 问题分别修到位了吗？
2. 30 秒内新用户能理解产品定位（多元宇宙模拟器 + 档案研究员心智）吗？
3. 核心价值（创造平行宇宙、看角色命运分叉）是否被传达？
4. 空态是否用"诱饵"（示例内容、馆藏推荐）代替了"还没有"？
5. 跳转路径（入口发现性）清晰吗？

## 共识汇总 prompt（主程序用）

跑完 3 agent 后，主程序做 synthesis。不需要再派 agent，直接在主上下文汇总：

```
## Round N 共识汇总

### 三方共指的问题（严重）
- {VD + IxD + PM 都指出的}
- {两人及以上指出的}

### 单方指出的次严重问题
- {VD 独指}
- {IxD 独指}
- {PM 独指}

### 视角分歧（不强行合并）
- {VD 说要 X 但 IxD 说要 Y}
- 处理：按用户前期对齐的方向走；如未对齐，向用户明问

### Round N+1 修复清单
1. {共识第一优先}
2. {共识第二优先}
3. {共识第三优先}
```
